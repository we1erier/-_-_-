# ADR-0002. Автоматическое распределение курьеров по геопозиции

**Дата:** 2026-09-11  
**Статус:** принято  

## Контекст
После подтверждения заказа рестораном систему необходимо эффективно связать со свободным курьером, находящимся ближе к точке общепита, чтобы минимизировать время доставки.

## Рассмотренные варианты
1. **Пул заказов (Self-service):** заказ попадает в общий список, и курьеры самостоятельно выбирают удобный заказ вручную через мобильное приложение.
2. **Автоматическое гео-распределение:** фоновый воркер автоматически ищет ближайшего доступного курьера в радиусе N километров и назначает заказ на него с возможностью тайм-аута.

## Решение
Вариант 2 (Автоматическое гео-распределение).

## Последствия
**Плюсы:** Снижение времени ожидания клиента, оптимизация логистики, автоматизация рутинных действий курьера.  
**Минусы:** Усложнение архитектуры (требуется фоновый воркер диспетчеризации и интеграция с геосервисом/картами).  
**Что станет неверным, если решение пересмотреть:** Динамическая диаграмма С4, логика фонового воркера и интерфейс мобильного приложения курьера.
